# Lawkit

AI legal copilot for law firms and in-house counsel.

## Local development

Requirements:

- Node.js 18+
- npm

Install dependencies and start the app:

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — create a production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
- `npm run test` — run Vitest once

## Tech stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase

## Deployment

Deploy the frontend to any static hosting platform that supports Vite builds, and deploy backend logic with Supabase Edge Functions.
